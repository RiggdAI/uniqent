# Learning Note

1. Ask for the child's identifier (never full name in shared contexts), the date, and the observed behaviour.
2. Select the relevant developmental milestone from the approved framework (e.g. physical, social, language, cognitive).
3. Write the note in factual, strengths-based language; avoid labels or comparisons to other children.
4. Store the note in the child's private record folder — never in a shared or class-level file.
5. Flag any observation that may indicate a wellbeing concern for confidential staff review.

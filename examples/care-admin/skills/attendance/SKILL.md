# Attendance

1. Confirm the class name and today's date with the user.
2. List enrolled children for that class; ask the user to mark each as present, absent-excused, or absent-unexplained.
3. Write the completed register to the attendance file for the day.
4. Identify any children marked absent-unexplained and generate a flagged-absence notice for each.
5. Send or surface the notices to the class coordinator for follow-up.

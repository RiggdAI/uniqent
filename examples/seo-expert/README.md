# SEO Expert

A ready-to-install brain for **search engine optimization** — technical audits, keyword research, on-page fixes, and content strategy.

## Tools (MCP)

- **Brave Search** — fresh web/SERP research
- **Google Search Console** — your site’s impressions, clicks, and positions
- **Keywords Everywhere** — keyword volume, difficulty, and competitive data
- **Web Fetch** — pull and analyze any page

The three search tools run over [Smithery](https://smithery.ai) — bring one `smithery_api_key` (plus each tool’s own subscription where required). No secrets travel in the bundle.

## Skills

Keyword research, technical audit, on-page optimization, and content briefs. For deeper, ready-made SEO skills, browse the hub — e.g. `uniqent hub skills seo` surfaces `nextjs-seo-audit` (a 11-skill audit suite) and `seo-content-skills` (a full content production suite).

> Bring your own Smithery + Search Console access; install into Claude Code, Hermes, or OpenClaw.

# Uniqent Studio (`apps/studio`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** A local-first web app (Node API over `@uniqent/builder` + React/Vite SPA) that builds a brain from scratch and exports a signed `.uniqent`, verified by a live browser run.

**Architecture:** `StudioSession` wraps a `Brain`; a thin `api.ts` maps HTTP → session; `node:http` server serves `/api` + the built SPA. React UI is panels over the API. See `docs/superpowers/specs/2026-05-31-studio-design.md`.

**Tech Stack:** TypeScript ESM, `@uniqent/builder`/`core`/`spec`, `node:http`, React 18 + Vite, vitest.

> **Commit policy:** Stage as you go; land all of M3 as ONE squashed feature commit. The live browser test must pass before the squash commit.

---

### Task 1: Scaffold `apps/studio` (server side)

- `apps/studio/package.json` (`@uniqent/studio`, type module; deps `@uniqent/builder`/`core`/`spec` workspace; dev: vitest, vite, react, react-dom, @vitejs/plugin-react, @types/react, @types/react-dom, @types/node). Scripts: `build` (server tsc + `vite build` web), `build:server` (`tsc -p tsconfig.json`), `build:web` (`vite build web`), `typecheck`, `test` (vitest run), `start` (`node dist/server/index.js`), `dev`.
- `apps/studio/tsconfig.json` (extends base; `rootDir src`, `outDir dist`, include `src/server`). Exclude web from server tsconfig.
- `pnpm install`.

### Task 2: `StudioSession` + tests (TDD)

- `src/server/session.ts`: class wrapping a `Brain`, default meta. Methods: `state()`, `setMeta`, `setPersona`, `addFact({text,importance?})`, `addMcpFromCatalog(id)`, `addSkillFromCatalog(name)`, `reset()`, `catalog()`, `export({sign})`.
  - `state()` returns `{ components, validation: ValidationResult, manifest: Manifest | null, credentials, permissions }` derived from `brain.toBundle()` (guard: building a manifest requires meta; Brain.create always has meta, so always buildable).
  - `export({sign})`: `const bundle = brain.toBundle(); validate; let out = bundle; if (sign) out = await core.sign(bundle, this.keypair.privateKey); const bytes = await core.pack(out, {skipValidation:false}); verify if signed;` return `{ filename: `${name}.uniqent`, bytesBase64, signed, validation }`.
  - keypair generated lazily via `core.generateKeypair()`.
- `src/server/session.test.ts`: fresh session valid after meta+persona+catalog mcp+skill; github credential surfaced; export bytes unpack+validate; signed export verifies.

### Task 3: `api.ts` + tests (TDD)

- `src/server/api.ts`: `handleApi(session, method, path, body): Promise<{status, json}>`. Routes:
  - `GET /api/state` → session.state()
  - `GET /api/catalog` → session.catalog()
  - `POST /api/meta` → setMeta(body); state()
  - `POST /api/persona` → setPersona(body.persona); state()
  - `POST /api/memory` → addFact(body); state()
  - `POST /api/mcp/catalog/:id` → addMcpFromCatalog(id); state()
  - `POST /api/skill/catalog/:name` → addSkillFromCatalog(name); state()
  - `POST /api/reset` → reset(); state()
  - `POST /api/export` → session.export(body)
  - unknown → 404.
- `src/server/api.test.ts`: drive handleApi through a full build sequence; assert state validity + export.

### Task 4: HTTP server

- `src/server/index.ts`: `node:http` server. `/api/*` → read body, call `handleApi`, write JSON. else serve static files from `dist-web` (index.html fallback for SPA). Port from `UNIQENT_STUDIO_PORT` or 4173. Log the URL.

### Task 5: React + Vite web

- `web/index.html`, `web/vite.config.ts` (plugin-react; `root: web`; `build.outDir: ../dist-web`; `server.proxy['/api'] -> http://localhost:4173`), `web/tsconfig.json` (DOM, react-jsx, bundler resolution).
- `web/src/api.ts`: typed fetch client.
- `web/src/main.tsx`, `App.tsx` (sidebar + active panel + status bar + export), `panels/` (Identity, Stack, Skills, Memory, Config, Review), `styles.css` (polished).
- Each panel calls the API and refreshes state. Status bar shows validation/secret/credential summary.

### Task 6: Build + live browser e2e (acceptance gate)

- `pnpm --filter @uniqent/studio build` (server + web).
- Start server; drive a real browser (gstack/playwright), screenshot each step; complete the build-a-brain flow; download `.uniqent`; assert it validates + is signed via a small node check.
- Capture screenshots as evidence.

### Task 7: Gate + status + squash commit

- `pnpm build && pnpm typecheck && pnpm lint && pnpm test && pnpm format:check` green (eslint config may need a web override for React/DOM globals + .tsx — add if needed).
- Update `CLAUDE.md` status → M3 complete.
- Squash commit `feat: M3 Uniqent Studio (local-first visual builder)`.
